# Contributing to FlyonVOX Dictate

Issues, bug reports, documentation improvements, and focused pull requests are welcome.

Before opening a pull request:

1. Explain the user-facing problem and the proposed change.
2. Keep changes focused; avoid committing model files, build output, virtual environments, or recordings.
3. Test the affected workflow on Windows when possible.
4. Update the README or configuration documentation when behavior changes.
5. Include clear reproduction steps for bug fixes.

The project is still in early preview, so interfaces and supported models may change.
