# Security and privacy

Please do not include microphone recordings, clipboard contents, credentials, or other private data in public issues.

Report suspected security vulnerabilities privately to the project maintainer before opening a public issue. Include the affected version, operating system, reproduction steps, and any relevant logs with sensitive information removed.

FlyonVOX Dictate uses microphone input, clipboard access, simulated keyboard input, local model files, and optional network downloads. These capabilities are part of the normal application workflow and should be reviewed before running untrusted builds.
